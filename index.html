Finance API

This server provides the data for The Art of Finance React site. Click a request below to see what it returns.

Available Requests

GET /api/assets

Returns all 8 alternative asset classes. Each one has an id, name, image name, category, risk level, typical return, liquidity, and description.

View All Asset Classes
GET /images/{img_name}

Returns the picture for an asset class, using the img_name from the list above.
